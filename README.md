# 🔮 Vibe Coding Projects

Welcome to the **Vibe Coding** repository! This is a collection of production-grade, highly-aesthetic applications developed entirely using agentic AI coding tools (such as Claude Code, Antigravity, Cursor, and Windsurf) guided by prompt-driven software design.

Vibe coding is the practice of designing, structuring, and iterating on codebases by communicating intent, requirements, and design feedback to AI agents rather than writing boilerplates manually. This repository demonstrates how complex mobile and web systems can be built, sync'ed, and deployed with zero manually written boilerplate.

## 💡 What is Vibe Coding?

Vibe coding isn't just about letting AI generate lines of code. It is **prompt engineering, context architecture, and design review combined**. To build robust apps like the ones in this repo, we followed a structured lifecycle:

1. **Spec-Driven Prompting**: Providing agents with a strict design language token grid (colors, shadows, roundings) and a feature outline before they touch the code.
2. **Iterative Feedback Loop**: Reviewing agent actions step-by-step, evaluating components on physical and virtual simulators, and guiding fixes.
3. **Monorepo / Multi-platform Scaling**: Guiding agents to modularize features (database logic, UI constants, backend connectors) so they can be easily understood and updated.
